# AquaSense — Smart Automated Water Quality Monitoring System

AquaSense is an intelligent, automated water quality monitoring system built on IoT architecture. It continuously measures key water quality parameters in real time and provides actionable analytics and instant threshold alerts.

## 🚀 Key Features
- **Real-Time Multi-Parameter Sensing**: pH, Turbidity, Dissolved Oxygen (DO), Temperature, Total Dissolved Solids (TDS), and Conductivity.
- **Interactive Live Dashboard**: Live updating gauges and real-time Chart.js visualizations.
- **Automated Alerts**: Threshold-based notification alerts.
- **AI-Driven Analytics**: Trend detection and anomaly tracking.

## 🛠️ Tech Stack
- Frontend: HTML5, Vanilla CSS3 (Custom design system), Vanilla JavaScript (ES6+)
- Visualization: Chart.js
- Hardware / IoT: ESP32 / Arduino, Water Sensor Suite
- Architecture: Cloud Logging & Live Telemetry

## 📂 Project Structure
- `index.html` - Main landing page & monitoring dashboard
- `style.css` - Custom styling, responsive layout, animations
- `app.js` - Real-time sensor simulation, Chart.js graphs, interactions
- `assets/` - Project imagery and diagrams
